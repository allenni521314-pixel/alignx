# 因果COSmo升级方案 - 实施文档

## 📋 升级概述

将现有COSmo系统从"语义关键词分析"升级到"因果状态转移分析"。

### 核心哲学升级

| 维度 | 传统COSmo | 因果COSmo |
|------|-----------|-----------|
| **核心视角** | 商品有什么属性？ | 商品解决了人类的什么状态差距？ |
| **分析深度** | 关键词出现频率 | 因果链条完整性 + 证据质量 |
| **优化目标** | 关键词覆盖度 | 因果效应可信度 + 副作用透明度 |
| **用户理解** | 搜索什么关键词 | 有什么未被满足的状态差距 |

## 📊 三个因果维度详解

### 🎯 维度1：状态差距覆盖度 (State Gap Coverage)
**得分范围**: 0-100

**计算逻辑**:
```
覆盖率 = Σ(每个差距的覆盖程度 × 差距重要性) / 总差距数
        - 覆盖程度：Listing中描述该解决方案的详细程度
        - 差距重要性：该差距在目标用户中的普遍程度
```

**提升方向**:
- ✅ 明确指出"解决了用户的什么问题"（不仅是"有什么功能"）
- ✅ 用具体场景描述用户痛点
- ❌ 不要只说功能，不说解决了什么问题

---

### ⚙️ 维度2：因果机制清晰度 (Mechanism Clarity)
**得分范围**: 0-100

**计算逻辑**:
```
清晰度 = Σ(机制链条完整性 × 证据强度) / 机制总数
        - 链条完整性：因果描述有几个环节？
        - 证据强度：是否有测试数据、认证、用户证言？
```

**提升方向**:
- ✅ "1.5米跌落测试 → 四角气囊吸收冲击 → 手机完好率99%"
- ❌ "军工级防摔"（没有机制说明，没有证据）

---

### ⚠️ 维度3：副作用透明度 (Side Effect Transparency)
**得分范围**: 0-100

**计算逻辑**:
```
透明度 = Σ(已提及的副作用严重程度) / Σ(所有副作用严重程度)
        - 诚实告知代价 = 建立信任 = 长期更高转化
        - 隐瞒副作用 = 高退货率 + 差评
```

**提升方向**:
- ✅ "为了极致防摔，我们增加了35%厚度"
- ✅ "无线充电速度降低15%以获得更强磁吸"
- ❌ 只说优点，对代价绝口不提
