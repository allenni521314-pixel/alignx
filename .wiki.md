# Project Summary
AlignX is a SaaS platform designed for Amazon sellers, aimed at enhancing their operational efficiency and e-commerce performance. It provides a comprehensive suite of tools for optimizing product listings, managing data, and leveraging AI-driven insights to boost market engagement. Key features include user authentication, competitor analysis, advertising strategies, and performance tracking, all tailored to help sellers improve visibility and profitability in the marketplace.

# Project Module Description
- **Landing Page**: Displays AlignX features, pricing, and trial options.
- **Dashboard**: Central hub for monitoring sales metrics with advanced visualization tools.
- **ASIN Manager**: Manages ASIN product details with proxy fetching and enhanced filtering.
- **User Intent Analysis**: Analyzes frequent search queries for product insights.
- **Listing Diagnosis**: Optimizes listings using backend proxy-fetch for data extraction.
- **Market Validation Panel**: Provides insights on product health.
- **Ad Analytics**: Evaluates advertising performance metrics.
- **Ad Optimizer**: Suggests improvements for ad performance.
- **Review Analysis**: Compares customer reviews against listings.
- **Knowledge Graph**: Visualizes relationships between products and users.
- **Consumer Intent**: Analyzes user search intent with automatic history saving.
- **Settings**: Manages user accounts and store integrations, now includes super admin functionalities.
- **Login**: Facilitates user registration and login.
- **Auth Callback**: Manages user authentication state redirection.
- **Competitor Analysis**: Compares ASINs with competitors using AI insights.
- **URL Fetch**: Automatically extracts listing information from Amazon.
- **Parse HTML**: Fetches and parses HTML from Amazon product pages.
- **Listing Diagnosis History**: Allows users to view and analyze historical listing diagnoses.
- **ASIN Analysis**: Analyzes ASIN performance with AI insights and recommendations.
- **PDF Report Export**: Generates detailed PDF reports.
- **Cosmo Translator**: Enhances COSMO relations with improved history management.
- **PreLaunchTest**: Supports multi-image uploads with history tracking and PDF export options.
- **Intent Matrix**: Visualizes relationships based on COSMO analysis.
- **Health Report**: Monitors product health and performance metrics.
- **Profit Pilot**: Optimizes profit margins and sales strategies.
- **Optimization Suggestions**: Provides actionable recommendations for product optimization.
- **Optimization Timeline**: Tracks optimization steps and performance metrics.
- **Super Admin Module**: Allows super admins to manage all sellers' ASINs and listings, user roles, and access comprehensive platform statistics.

# Technology Stack
- **Backend**: Python, FastAPI, SQLAlchemy, Alembic, httpx, BeautifulSoup, curl-cffi, undetected-chromedriver, Playwright
- **Frontend**: React, TypeScript, Tailwind CSS, Vite
- **Database**: PostgreSQL (via SQLAlchemy)

# Usage
1. **Install Dependencies**: Run `pnpm install` in the frontend directory and ensure necessary backend libraries are included.
2. **Build the Project**: Execute `pnpm run build` in the frontend directory to create production builds.
3. **Run the Application**: Use appropriate commands to start the backend and frontend servers.
